## 来源、使用范围与数量

来源为 [CMU / Tom M. Mitchell 的 Machine Learning 第4章人脸材料](https://www.cs.cmu.edu/~tom/faces.html)，官方允许注明出处的免费教学使用。初始实现按原页面归功于 Jeff Shufelt；本项目使用图像数据，不将官方神经网络代码算作自研算法。参考[原始说明](https://www.cs.cmu.edu/afs/cs.cmu.edu/project/theo-8/faceimages/docs/hw97.tex)。这是公开教学许可记录，不能填成新参与者的个人同意书；课程是否接受替代样本由教师确认。

官方完整包 SHA256：`74a1c594babd985515be58c0c679df283e6b1b9ec0a84d3fc32f9f88c27713f4`。

- 20 人、624 张有效原始图像，128×120，每人28–32张。排除16张 `.bad` 和1248张缩放版本，以及1个包元数据文件。同一图像的缩放版本不算新增照片。
- 同时检查文件字节与解码像素去重；有效原始图像没有重复。没有根据检测是否成功筛选样本或挑选人员。
- 原图、原始别名映射只保存在 Git 忽略的 `.codex-run-logs/cmu-faces-20261115/`；公开清单使用 CMU01–CMU20。这是化名化，不宣称不可逆匿名化。不发布原图或人脸特征。
- 数据同属历史受控采集，没有独立拍摄会话信息，不能证明跨会话、现场摄像头、活体或树莓派效果。此前私人 `id/`、`test/` 目录未读取。

## 固定协议

划分在提取特征前确定，按源目录排序编号，各人排序后用固定种子 `20261115 + 身份序号` 打乱。12个已知身份每人登记16张、标定8张、余下最终测试；另外4个陌生身份只用于标定，最后4个陌生身份只用于最终测试。未知身份不登记，标定和测试的未知身份也不重叠。

| 集合 | 已知图像 | 未知图像 | 合计 |
|---|---:|---:|---:|
| 登记 | 192 | 0 | 192 |
| 标定 | 96 | 121 | 217 |
| 最终测试 | 90 | 125 | 215 |

阈值只用标定集选取：从观测分数构造候选，要求 FAR≤5%，优先最少已知身份错误（拒识+认错人），再选择较低 FAR、较高阈值。写入 `frozen_threshold.json` 后才提取最终测试特征；最终结果不参与调参。两种流程各自标定，阈值不能混用，也没有导入正在运行的门禁服务。

检测失败按拒绝计，保留在全部分母和逐图CSV中。`accuracy=(已知正确接受+未知拒绝)/全部测试图像`；`FAR=未知接受/全部未知`；`FRR=已知拒绝/全部已知`，认错人另列，不算正确。低 FAR 不能单独证明识别可用，尤其大量未知图像也检测失败时。

## 最终测试结果

| 指标 | 现有完整服务流程 | 整幅肖像特征诊断（不含检测） |
|---|---:|---:|
| 标定阈值（仅本实验） | 0.7468607943840067 | 0.8993704511012635 |
| 已知身份正确识别 | 14/90（15.56%） | 85/90（94.44%） |
| 已知身份拒识 FRR | 76/90（84.44%） | 5/90（5.56%） |
| 已知认错身份 | 0 | 0 |
| 未知误接受 FAR | 2/125（1.60%） | 0/125（0%） |
| 综合 accuracy | 137/215（63.72%） | 210/215（97.67%） |
| 已知测试检测失败 | 69/90 | 未运行检测 |
| 未知测试检测失败 | 96/125 | 未运行检测 |

完整流程保持现有 `FacePipeline`：解码→Haar单脸检测→自研预处理→2891维 uniform LBP→余弦比对。624张中仅155张检出单脸（24.84%），469张失败；登记192张中仅44张提取成功，CMU08没有成功登记特征，其测试图像仍全部计入。最终检出单脸的已知图像为21张，正确14张（条件正确率66.67%）；检出的未知图像29张中误接受2张（条件 FAR 6.90%），揭示整体 FAR 被大量检测拒绝稀释。

整幅肖像诊断直接将已经提供的完整肖像送入同一自研预处理/LBP/比对，完全跳过检测。它说明在本数据和划分下特征比对环节表现较好；也可能利用肖像背景、头部轮廓等信息，不能用97.67%替代主服务63.72%，更不能据此声称现场人脸门禁通过。诊断JSON复用的 `detected` / `*_detection` 字段仅表示提取成功，不代表执行检测。

0/125的观测误接受不证明真实误接受概率为零。此次没有根据最终测试结果修改检测器或选取更好看的样本。后续检测优化应另立实验，提前固定方法与独立评估集；不能在本次测试集上反复调参后沿用“独立最终测试”的结论。

## 耗时与回归

Windows AMD64、Python3.10.11、OpenCV4.13.0、NumPy2.0.2；不是树莓派数据。完整流程的432次标定/测试尝试均计时，含读取、解码、检测、预处理、LBP、比对，不含HTTP和设备动作：全部平均2.889ms、P95 7.376ms；成功提取111次平均6.331ms，失败321次平均1.699ms。失败提前结束使整体平均偏低。肖像诊断432次平均2.031ms、P95 2.335ms，因没有检测不能直接当成完整流程加速结果。

新增11项合成协议回归全部通过：固定划分/去重口径、未知身份隔离、归档路径保护、检测失败分母、认错人与拒识分开、阈值约束、清单篡改拒绝、先冻结后测试及测试结果不能反向影响阈值。原有25项人脸算法/访问拒绝/模拟联动回归全部通过。两组不读取真实私人照片、不驱动GPIO；与624张真实公开图像的离线实验分别计数。
