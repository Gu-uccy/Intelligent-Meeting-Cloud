| ② 特征提取 | 分块均匀模式 LBP + L2 归一化 | `scripts/lbp_face.py` | 预处理人脸图 | 2891 维特征向量 |

## 二、各步骤算法说明

### ① 预处理

1. 灰度化：`gray = 0.299R + 0.587G + 0.114B`，与 OpenCV `cvtColor` 权重一致；
2. 尺寸归一化：双线性插值到 112×112（与 ArcFace 输入尺寸一致，保证特征维度可比）；
3. 直方图均衡化：拉伸灰度对比度，抹平光照差异（与综II门禁系统 `smart_door_system.py` 使用的 `equalizeHist` 同口径）。

**改进理由**：光照是识别最大干扰源。实测综II会议室内光线随窗帘、投影变化明显，直接使用原始灰度图会导致同一个人在不同时刻特征差异大；均衡化后特征更稳定。

### ② LBP 特征

1. 对每个像素计算 8 邻域二值模式（邻居 ≥ 中心取 1），得到 8 位二进制码；
2. 均匀模式映射：跳变次数 ≤ 2 的模式保留（压缩为 0~58），其余映射为 59，共 59 维直方图——均匀模式占自然图像模式 90% 以上，降维且抗噪；
3. 分块：112×112 分为 7×7=49 块，每块 59 维直方图级联为 2891 维特征（保留空间位置信息，判别力远高于整图直方图）；
4. L2 归一化后余弦相似度比对。

**改进理由（相对整图直方图/相对库方案）**：
- 相对整图直方图：分块保留眼睛、鼻子、嘴的局部位置信息，识别准确率更高；
- 相对 DeepFace ArcFace：无需下载模型、纯 numpy 可运行，适合树莓派 CPU 场景，且特征可解释（纹理直方图），便于课程答辩说明。

### ③ 余弦相似度比对

- 相似度 = 特征向量夹角余弦，取值 [-1, 1]，对特征幅值不敏感；
- 一人注册多张照片时，取与该人所有注册特征的最大相似度作为候选分数；
- 取库中最高分者作为识别候选，同时保留全部分数供日志审计。

### ④ 阈值标定

- 在测试集上扫描 θ（0.50~0.90），计算每个 θ 下的 FAR（误识率）与 FRR（拒识率）；
- 选择 **FAR ≤ 0.05 前提下 FRR 最小** 的 θ 作为系统阈值；
- 算法自测（合成特征向量）输出曲线见 `results/阈值标定曲线.png`，真实人脸测试按 `tests/face_test_protocol.md` 执行。

## 三、课堂思考题回答

### 问题1：为什么用别人训练好的模型或阈值不算“半自主开发”的自研？

阈值和模型参数是识别系统行为的一部分，不是“拿来就能用的黑盒”：

1. 直接使用别人训练好的模型/阈值，意味着系统在“什么相似度算同一个人”这个安全问题上完全依赖他人经验，无法解释为什么这样设、无法针对自己的数据调整；
2. 换数据集后，模型与阈值的最优组合会变化（不同光照、不同摄像头、不同人群分布），不标定就无法保证 FAR/FRR 达到安全要求；
3. 课程要求“半自主开发”的本质是掌握关键环节的原理并能自行调整。本组的做法：特征用自研 LBP（理解原理并可修改），阈值在自己测试集上标定（见 run_face_eval.py），这样每一步都能解释“为什么”。

### 问题2：什么是“特征”？为什么换一张照片还能认出同一个人？

- “特征”是把一张人脸压缩成一个固定长度的数值向量（如 LBP 分块直方图 2891 维，或 ArcFace embedding 512 维），向量中编码的是与身份相关、跨照片稳定的信息（五官纹理分布、局部灰度结构），而非某一时刻的像素快照；
- 同一个人在不同照片里，虽然光照、角度、表情有变化，但**脸部的纹理结构特征保持稳定**，所以提取出的特征向量彼此接近（余弦相似度高）；
- 不同人的特征向量差异大（相似度低）。因此“换一张照片”仍能通过相似度找到最近身份，这是人脸识别“认出同一个人”的本质。

### 问题3：什么是“失败不放行”？为什么门禁必须“失败不放行”？

- “失败不放行”（fail-closed）指：当识别结果低于阈值、或系统不确定时，默认动作是**拒绝放行**（保持门锁/拒绝登录），而不是放行；
- 与“失败放行”（fail-open）对比：fail-open 会在不确定时开门，陌生人可能混入；fail-closed 宁可把本人拒之门外，也不放过陌生人；
- 门禁是安全场景，误放行（FAR 高）的后果远大于误拒绝（FRR 高），因此本组业务动作层一律 fail-closed：拒绝 → 保持锁定 + 提示重试 + 写失败日志（见 `docs/business_linkage.md`）。
