# 人脸数据使用与授权记录

## 2026-11-15：CMU 公开教学数据

用户选择 CMU 后，已从 [CMU 官方页面](https://www.cs.cmu.edu/~tom/faces.html) 获取 Machine Learning 第4章人脸材料。官方允许注明出处的免费教学使用。本项目注明 CMU / Tom M. Mitchell，原页面初始实现归功于 Jeff Shufelt。本记录是公开数据许可依据，不是对图中人物新收集的个人授权；数据集能否替代课程采样由教师确认。

实际整理20人624张128×120有效原图，每人28–32张，排除缩放版和 `.bad`；按CMU01–CMU20编号。12人登记/标定/最终测试，另4人仅未知标定、4人仅未知测试。来源、包哈希、每图哈希、固定划分、原始结果见 [CMU评估报告](../../analysis/cmu-faces-2026-11-15/README.md)。失败图像全部保留在实验分母。

原图和原始别名映射仅存本机Git忽略的 `.codex-run-logs/cmu-faces-20261115/`；特征只在离线评估进程内存中，不向仓库或线上底库写入。公开的是化名化清单与指标，不发布照片、签名或真实姓名。此数据来自同一历史受控采集，缺少跨拍摄会话信息。演示结束后按课程需要删除本机缓存；重现时从官方重新获取。

已补公开图像离线指标；现有完整流程已知正确率14/90、FRR76/90、FAR2/125，检测失败较多，不能声明识别达标。目标树莓派/现场相机与设备联动仍待验；整幅肖像特征诊断不能替代完整流程成绩。

## 个人样本采集仍待办

2026-11-14用户确认暂时没有本人授权的参与者照片。没有读取项目旧 `id/`、`test/` 私人照片，也不将其存在视为授权。个人数据采集不因改用CMU而自动完成。

采集前向每位参与者说明课程实验目的、提取的特征、保存位置、保留期限、访问人员、撤回与删除方式；取得本人有效授权，或使用教师提供且许可符合课程使用范围的数据。

原图和特征均需要保护。个人原图放仓库外受控目录；服务端仅保存特征，不保存上传原图，特征默认在忽略的 `MachineLearning/human_face/local_face_data/`。管理员DELETE接口可删除身份特征，日志及离线原图另行清理。

为每位对象私下记录：匿名编号、授权凭据位置、授权日期、使用范围、撤回联系人、删除期限；不向公共仓库上传签名和真实姓名。至少3名对象、每人至少10张，登记/标定/最终测试相互独立；按会话或拍摄时间分组，另准备独立未知身份用于标定和最终测试，冻结阈值后再测最终集。合成向量测试不计入图像数量。
