# 版本冻结候选与演示视频初稿脚本（第 11 周）

## 一、版本冻结候选（v1.0-rc1）

| 项 | 内容 |
| --- | --- |
| 候选版本号 | `v1.0-rc1` |
| 冻结日期 | 2026-11-08 |
| 冻结范围 | 传感器接口 `api-v1.0`（`/api/current`、`/api/control`、`/api/history`、`/api/export/csv`、`/chart/*`）；3D 页面 `Room3D` 与状态绑定；工程化 1（权限/审计）与工程化 2（心跳/断连）的接口契约；功能扩展 1/2 的接口契约 |

### 1.1 版本号规则

`主版本.次版本-阶段`：主版本对应破坏性变更，次版本对应新增可选字段或功能，阶段为 `rc{n}`（候选）或无后缀（正式）。

### 1.2 标签

```powershell
git tag -a v1.0-rc1 -m "第11周版本冻结候选：api-v1.0 + 3D 闭环 + 工程化与功能扩展契约"
git push origin v1.0-rc1
foreach ($w in 4..11) { git tag -a "w$w" -m "第 $w 周里程碑"; git push origin "w$w" }
```

## 二、按步骤跑起来

完整命令见 `week7-8/README.md` 第四节；此处为最小可跑路径（3 条命令 + 1 个地址）：

```powershell
cd Flask; pip install flask flask-cors matplotlib numpy; python unified_meeting_room_system.py
cd FrontEnd\Intelligent_meeting_cloud; npm install; $env:VITE_SENSOR_PROXY_TARGET="http://127.0.0.1:5000"; npm run dev
# 浏览器打开 http://127.0.0.1:5173/room-3d
```

环境要求：Node ≥18、Python ≥3.10；无树莓派时服务自动进入模拟模式并打印提示。

## 三、演示视频初稿脚本（5 分钟，可直接照读）

| 时间 | 画面 | 口播（照读） | 操作 |
| --- | --- | --- | --- |
| 0:00-0:20 | 仓库目录树 | “这是我们智能会议室系统的第 9 到 11 周交付。代码在仓库主目录，提交材料在 `week7-8` 和 `week9-11` 两个文件夹里，每份文档对应任务书的一条要求。” | 打开文件夹，指 `docs/`、`scripts/`、`results/` |
| 0:20-0:40 | 架构图 | “整条链路是：传感器每 3 秒采一次数据，Flask 通过 `/api/current` 对外提供 17 个字段，前端每 3 秒轮询一次，把状态映射到 Three.js 场景的物体属性上。” | 展示 `docs/01_状态字段表.md` |
| 0:40-1:30 | 终端 + 浏览器同屏 | “先起传感器服务，日志每 3 秒一行；再起前端，打开 3D 会议室页面。右上角这个时间是接口返回的 `timestamp`，不是前端自己造的。” | 起服务 → 开页面 → 指右上角时间 |
| 1:30-2:20 | 3D 场景 | “现在开门、开灯：点按钮后 3 秒内门扇旋转 93.6 度、顶灯亮到 80%，左侧面板同步显示‘门禁 已开启、照明开启’。走动人形会跟着人数变化。” | 点开门/开灯 → 指面板 |
| 2:20-3:00 | 停后端检验 | “任务书说停掉后端还显示正常内容就是写死的，所以我们主动停一次。停掉后页面会出现红色断连横幅，数据不可用、控制按钮禁用；重启后 3 秒内自动恢复。” | 停 Flask → 指横幅 → 重启 |
| 3:00-3:40 | 接口与错误处理 | “接口已经冻结成 api-v1.0：路径、参数、返回字段、错误码都写进文档。比如非法 action 返回 400，用 GET 打控制接口返回 405，未知路径 404。这是我们自动化用例的结果：19 条通过 17 条，两条偏差已登记为缺陷。” | 展示 `results/接口测试用例结果.csv` |
| 3:40-4:20 | 性能测试 | “性能必须做，所以跑了 3 轮：顺序 100 次 P95 16 毫秒左右，并发 20×50 吞吐约 1000 请求每秒、零错误，服务内存稳定在 121 MB。三轮结果在同一区间，说明可重复。” | 展示 `results/性能测试结果.md` |
| 4:20-4:50 | 工程化与扩展 | “工程化做了两项：权限与操作审计、心跳与断连重连；功能扩展做了两项：多会议室智能调度、数据分析与报告。都有接口契约和用例编号。” | 翻 `docs/01`、`docs/02`、`docs/03`、`docs/04` |
| 4:50-5:00 | 缺陷表 | “9 个缺陷都有编号、定位、修复方案和回归用例，跟踪表在 `docs/07`。版本是 v1.0-rc1 候选。” | 指 `docs/07_缺陷跟踪表.md` |

### 3.1 录制要求

- 分辨率 1920×1080，一次录完不剪辑；
- 终端字号 ≥16pt，保证日志可读；
- 语音清楚念出数字（3 秒、93.6 度、16 毫秒、121 MB），这些是判分点；
- 文件命名 `results/演示视频_v1.0-rc1.mp4`，时长 5:00 ± 15 s。
