## 关于分支

`fullchain` 分支是**本学期的最终版本**（真实 MySQL + Spring Boot + 自研 LBP 人脸 + 设备层 + 3D 全链路打通，含 RBAC 鉴权与操作审计）。

`main` 分支保留学期中期的旧版本作为对照，未做改动。

## 关于答辩 PPT

答辩演示文稿不在本仓库内（`.gitignore` 把 `*.pptx` 视为生成物忽略），以课程系统提交的版本为准。
