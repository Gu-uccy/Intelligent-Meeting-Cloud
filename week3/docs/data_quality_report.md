# 第3周课堂实践作业1：会议室数据清洗与质量检查报告

## 一、作业概况

- 课题：智能会议室管理系统III——会议室数据清洗与质量检查
- 数据来源：本组综II智能会议室物联网监测控制系统导出的原始数据
- 清洗脚本：`scripts/clean_data.py`
- 原始数据：`data/raw/原始数据样例.csv`
- 清洗结果：`data/processed/clean_data_v1.csv`与 `data/processed/clean_sensor_data.csv`

## 二、原始数据说明

原始数据字段与综II综合传感器系统 `/api/export/csv` 导出格式保持一致，并增加“会议室”列；数值范围与 `unified_meeting_room_system.py` 中的传感器模拟逻辑一致。

原始数据共 **14152 条**，覆盖 2026-09-01 至 2026-09-28 共 4 周，301/302/501 三个会议室，08:00—22:00 每 5 分钟一条采样。

为完成“数据清洗与质量检查”课堂练习，原始数据中按教学要求注入了少量脏数据（重复记录、缺失值、异常值、会议室命名不统一、时间格式不统一、占用状态写法不统一），注入明细见 `data/raw/脏数据注入清单.json`，可逐条与清洗结果对照核验。

## 三、清洗过程与结果

### 1. 字段名称统一

| 原始字段（综II导出格式） | 统一字段 | 含义 |
| --- | --- | --- |
| 时间 | time | 当日时间（HH:MM:SS） |
| 时间戳 | timestamp | 完整时间戳（YYYY-MM-DD HH:MM:SS） |
| 会议室 | room_id | 会议室编号 |
| 温度(°C) | temperature | 温度（℃） |
| 湿度(%) | humidity | 相对湿度（%） |
| 光照 | light | 光照值（0~255） |
| 烟雾 | smoke | 烟雾值（0~200） |
| 距离(cm) | distance | 超声波距离（cm） |
| 人体检测 | motion | 是否检测到人体移动（0/1） |
| 占用状态 | occupancy | 是否有人（0/1） |
| 制冷/加热/加湿/除湿/照明/报警/自动模式 | cooling/heating/humidifier/dehumidifier/lighting/alarm/auto_mode | 设备状态 |

### 2. 时间格式统一

原始数据中时间戳存在多种写法：`2026-09-01 09:00:00`、`2026/09/01 09:00`、`09/01/2026 09:00`（月/日/年）、`2026-09-01T09:00`（ISO 风格）。清洗脚本依次尝试 6 种格式解析，统一转换为 `YYYY-MM-DD HH:MM:SS`，并按时间升序排列。

结果：全部 **14152** 条时间均解析成功。

### 3. 会议室编号统一

原始数据中同一会议室的编号存在多种写法，统一映射到数据库标准编号：

| 原始写法 | 统一编号 |
| --- | --- |
| 301 / room-301 / 3F301 / 301号 / 301室 | 301 |
| 302 / room-302 / 302室 / 302号 | 302 |
| 501 / room-501 / 5F501 / 501室 | 501 |

清洗后不存在无法归一的会议室编号。

### 4. 占用状态统一

原始数据中“占用状态”列存在 `1 / 0 / 有人 / 无人 / true / false / 2` 等多种写法，统一为 0/1：

| 原始写法 | 统一值 |
| --- | --- |
| 1 / 有人 / true / 是 | 1 |
| 0 / 无人 / false / 否 | 0 |
| 空值 | 缺失 |
| 2 | 缺失 |

### 5. 删除重复记录

按时间戳、会议室、温度、湿度、光照、烟雾、距离、人体检测、占用状态完全相同的标准去重，共删除重复记录 **39 条**。

### 6. 异常值检查

按综II系统传感器合理范围检查异常值，超出范围的记录置为缺失并统计：

| 字段 | 合理范围 | 异常记录数 | 异常值示例 |
| --- | --- | --- | --- |
| 温度 | 0~50℃ | 5 | 85℃、-5℃、52℃、58℃、-1℃ |
| 湿度 | 0~100% | 3 | 120%、-3%、105% |
| 光照 | 0~255 | 2 | 320、280 |
| 烟雾 | 0~200 | 1 | 350 |
| 距离 | 2~450cm | 3 | 999cm、-1cm、800cm |

> 说明：课堂要求至少识别“温度小于 0 或大于 50”一类异常值；本组进一步对湿度、光照、烟雾、距离按综II系统的合理范围做了同样的异常检查。

### 7. 缺失值检查与处理

| 字段 | 原始缺失 | 异常置缺失后合计 | 处理方式 |
| --- | --- | --- | --- |
| temperature | 24 | 29 | 置空保留，不做填充 |
| humidity | 22 | 25 | 置空保留 |
| light | 0 | 2 | 置空保留 |
| smoke | 0 | 1 | 置空保留 |
| distance | 16 | 19 | 置空保留 |
| occupancy | 28 | 30 | 置空保留 |

缺失处理策略：本数据集为传感器采样数据，缺失值不做插值填充（避免引入虚假读数），统一保留为空并在质量统计中给出缺失占比；第4周数据分析时按字段分别处理（例如占用率按“有人采样数 ÷ 有效采样数”计算口径已在周计划中写明）。

### 8. 清洗前后对比

| 指标 | 数值 |
