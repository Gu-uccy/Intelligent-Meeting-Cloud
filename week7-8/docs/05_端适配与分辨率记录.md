## 四、390×844 问题定位

| 编号 | 现象 | 直接原因 | 影响 |
| --- | --- | --- | --- |
| A | 顶部 LOGO「智会云」竖排成两行，右侧菜单被裁 | `LayoutNav.vue` 仅有 `@media (max-width:1180px)` 一档断点，导航项不换行 | 菜单不可完整进入 |
| B | 左侧控制栏与 3D 画布横向重叠 | `Room3D` 主栅格 `grid-template-columns: 336px minmax(0,1fr)`（`index.vue:1205`），980px 断点仅改 `1fr`，外层仍有 `padding:30px` | 3D 主视图被压缩 |
| C | 出现横向滚动条，内容右侧被截断 | `User/Layout/index.vue:178` 容器 `max-width:1400px; padding:30px`，子元素最小宽度溢出 | 触屏左右拖动体验断裂 |
| D | 8 张传感器卡片覆盖 3D 视口 | 窄屏断点下卡片栅格 `repeat(3, minmax(0,1fr))`（`index.vue:1652`）占满宽度 | 关键状态遮挡场景 |

## 五、窄屏整改方案

1. `LayoutNav.vue` 增加 ≤640px 断点：菜单折叠为汉堡抽屉，LOGO 使用 `white-space: nowrap`；
2. `User/Layout/index.vue:178`：`padding` 改为 `clamp(12px, 3vw, 30px)`，容器加 `overflow-x: hidden`；
3. `Room3D/index.vue:1627` 断点内：3D 视口 `height: 46vh`、`position: relative`；控制栏 `order: -1; overflow-y: auto; max-height: 40vh`；卡片栅格 ≤640px 改两列；取消覆盖画布的绝对定位；
4. 回归判定：无横向滚动条、3D 视口占屏高 ≥40%、导航可展开、卡片不遮挡画布（对应 TC-48）。

## 六、桌面端稳定性记录

| 项 | 结果 |
| --- | --- |
| 首屏加载（含 WebGL 初始化） | ≈1.2 s |
| 轮询期间帧率 | 无明显掉帧，`requestAnimationFrame` 持续运行 |
| 缩放与旋转 | `OrbitControls` 连续操作无跳变 |
| 切换会议室/氛围/视角 | 场景重建正常，`disposeScene` 释放几何与材质 |
| 窗口尺寸变化 | `ResizeObserver` 触发 `renderer.setSize`，无拉伸变形 |
