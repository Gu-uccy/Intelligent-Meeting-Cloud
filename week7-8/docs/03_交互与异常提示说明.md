# 交互操作与异常状态提示说明

> 对应第 7 周要求：至少一种点击、旋转、缩放或视角切换；异常状态有明显提示，不能只靠颜色区分。

## 一、交互操作清单

| 交互 | 实现方式 | 代码位置 |
| --- | --- | --- |
| 轨道旋转 / 缩放 / 平移 | `OrbitControls`：左键旋转、滚轮缩放、右键平移 | `Room3D/index.vue:4`、`336` |
| 三个视角预设切换 | 全景 `(10.8, 5.2, 11.2)`／正前方 `(0, 3.35, 11.8)`／俯视 `(0.02, 11.2, 0.02)`，`camera.position.copy + controls.target.copy` | `index.vue:114-136`、`863-869` |
| 三套氛围（灯光/雾/背景） | 日常办公／专注讨论／演示汇报，切换 `hemi/key/fill/lamp` 参数与雾色 | `index.vue:72-112`、`1030-1033` |
| 三间会议室切换 | 董事会议室 12 人／培训研讨室 24 人／创意协作室 16 人，切换即重建场景并恢复视角 | `index.vue:33-70`、`1025-1028` |
| 点击门扇开门/关门 | 射线拾取 `Raycaster`：命中门 → `toggleRoomDoor()` | `index.vue:965-979` |
| 点击顶灯开关灯 | 命中 `clickableLights` → `toggleRoomLighting()` | `index.vue:972-978` |
| 侧栏按钮控制灯 | `toggleRoomLighting()` → `POST /api/control`（device=lighting, source=room-3d） | `index.vue:897-932` |

交互设计要点：

- 点击后不是只改本地状态：`toggleRoomDoor` / `toggleRoomLighting` 先请求后端，成功时用服务端返回值落状态（`sensorData.value = {...result}`），失败才退回本地预览并标注 `local-preview`；
- 因此“点击 → 控制 → 回写 → 3D 更新”构成真实闭环；
- 实测：`POST /api/control {device:door,state:true}` 后 3 s 内门扇旋转 93.6°、门状态灯转绿、面板显示「门禁 已开启」，灯同理（`results/screenshots/3d_dooropen_light_1920x1080.png`）。

## 二、异常提示实现

顶部状态横幅承载文字信息，卡片与 3D 层做辅助强化，两条通道同时提示，不依赖颜色单独传达。

| 异常 | 提示通道 | 说明 |
| --- | --- | --- |
| 烟雾越界 | 卡片数值「烟雾 xx%」+ 顶部横幅「检测到烟雾，已触发报警，请立即疏散」+ 吊顶悬浮报警环与垂直光柱 + 三层半透明烟雾云 + 全场景淡红雾 | 报警环置于吊顶中心上方无遮挡处，任何视角可见 |
| 温度越界 | 卡片数值 + 横幅「温度越界 27.3℃（设定 20-26℃）」+ 空调模块蓝/橙切换 + 环境指示牌 | 文案带数值与设定区间 |
| 湿度越界 | 卡片数值 + 横幅「湿度越界 xx%（设定 40-60%）」+ 加湿模块自发光 | 同上 |
| 光照过暗 | 卡片数值 + 横幅「光照偏暗 xx lux（参考 ≥80）」+ 光照计高亮 | 同上 |
| 接口断连 | 横幅「接口断开，数据不可用（最后成功 hh:mm:ss）」+ 场景降饱和 + 控制按钮禁用 + 退避重连提示 | 断连态与正常态视觉区分明确 |
| 控制失败 | 横幅「控制指令未生效，已回退本地预览」+ 按钮状态复原 | 提示失败原因与当前生效状态 |

报警可见性验证：以受控服务构造 `smoke=180` 后截图（`results/screenshots/3d_alarm_1920x1080.png`），原信标位于 `(3.55, 2.86, -2.7)` 会被右侧墙体遮挡、烟雾云 `opacity=0.16` 几乎不可见，据此把报警载体改为吊顶悬浮环并提高烟雾云不透明度至 0.45，登记为 D-03。

## 三、异常横幅规则

### 3.1 组件

```vue
<!-- src/components/StatusAlertBar.vue，挂在 Room3D 顶部 -->
<template>
  <div v-if="alerts.length" class="alert-bar" :class="`level-${top.level}`">
    <i class="fa-solid" :class="top.icon" />
    <span class="alert-text">{{ top.text }}</span>
    <span class="alert-time">{{ top.time }}</span>
  </div>
</template>
```

### 3.2 触发规则（后端字段优先，前端不另立阈值）

| 条件 | 级别 | 文案 | 图标 |
| --- | --- | --- | --- |
| `smoke >= devices.alarm_threshold`（接口下发，缺省 100） | 危险 | 「检测到烟雾，已触发报警，请立即疏散」 | `fa-triangle-exclamation` |
| `temperature > temp_max + 1` 或 `< temp_min - 1` | 警告 | 「温度越界 27.3℃（设定 20-26℃）」 | `fa-temperature-high` |
| `humidity` 越界 | 警告 | 「湿度越界 xx%（设定 40-60%）」 | `fa-droplet` |
| 轮询连续失败 ≥ 2 次 | 危险 | 「接口断开，数据不可用（最后成功 hh:mm:ss）」 | `fa-plug-circle-xmark` |

规则要求：文案必须带数值与设定区间；危险级别同时触发三处——顶部横幅、场景内高亮、面板数值边框闪烁。

### 3.3 3D 层强化

1. 报警载体为顶部悬浮环 + 垂直光柱（`y=3.2` 起，半径 0.35），`depthTest: false` 保证不被墙体遮挡；
2. 烟雾云 `opacity 0.16 → 0.45`，颜色 `0x9ca3af → 0xd1d5db`，加微弱 `emissive`；
3. 报警时全场景淡红 `fog` + 一次性轻微镜头震动，通过形状与运动形成第二通道。

### 3.4 阈值改为接口下发

`/api/current` 已返回 `temp_min/temp_max/humidity_min/humidity_max`，前端取值：

```js
const hot = state.climate.temperature > Number(data.temp_max ?? 26);
const cold = state.climate.temperature < Number(data.temp_min ?? 20);
const wet = state.climate.humidity > Number(data.humidity_max ?? 60);
const dry = state.climate.humidity < Number(data.humidity_min ?? 40);
```

烟雾阈值由接口新增 `alarm_threshold` 下发，一处配置、两端一致（对应 D-04、D-06）。

## 四、交互验收自检

| 判据 | 现场操作 | 通过标准 |
| --- | --- | --- |
| 有点击交互 | 鼠标点门扇 | 门开/关，接口 `door_open` 同步变化 |
| 有旋转/缩放 | 拖拽、滚轮 | 视角变化平滑，无卡顿掉帧 |
| 有视角切换 | 点「全景/正前方/俯视」 | 相机跳转到预设，参数与文档一致 |
| 异常有明显提示 | 构造烟雾/温湿度越界/断连 | 出现文字横幅，文案含数值与区间 |
| 提示不遮挡关键信息 | 观察场景 | 报警时不遮挡门、人员、表格区域 |
