# 交互操作与异常状态提示说明

> 对应第 7 周要求：「至少有一种点击、旋转、缩放或视角切换；异常状态要有明显提示，不能只靠颜色区分」。

## 一、交互操作清单（均已实测）

| 交互 | 实现方式 | 代码位置 | 是否实测 |
| --- | --- | --- | --- |
| 轨道旋转 / 缩放 / 平移 | `OrbitControls`（鼠标左键旋转、滚轮缩放、右键平移） | `Room3D/index.vue:4`、`336` | 是（页面可正常拖拽缩放） |
| 三个视角预设切换 | 全景 `(10.8, 5.2, 11.2)` / 正前方 `(0, 3.35, 11.8)` / 俯视 `(0.02, 11.2, 0.02)`，`camera.position.copy + controls.target.copy` | `index.vue:114-136`、`863-869` | 是 |
| 三套氛围（灯光/雾/背景） | 日常办公 / 专注讨论 / 演示汇报，切换 `hemi/key/fill/lamp` 参数与雾色 | `index.vue:72-112`、`1030-1033` | 是 |
| 三间会议室切换 | 董事会议室(12人) / 培训研讨室(24人) / 创意协作室(16人)，切换即重建场景 + 恢复视角 | `index.vue:33-70`、`1025-1028` | 是 |
| **点击门扇开门/关门** | 射线拾取 `Raycaster`：门命中 → `toggleRoomDoor()`；灯命中 → `toggleRoomLighting()` | `index.vue:965-979` | 是（开门截图见 results） |
| 点击顶灯开关灯 | 同上，命中 `clickableLights` | `index.vue:972-978` | 是 |
| 侧栏按钮控制灯 | `toggleRoomLighting()` → `POST /api/control`（device=lighting, source=room-3d） | `index.vue:897-932` | 是 |

交互设计要点：

- 点击后**不是只改本地状态**：`toggleRoomDoor/toggleRoomLighting` 先请求后端，成功用**服务端返回值**落状态（`sensorData.value = {...result}`），失败才退回本地预览（`doorOverride` / `lighting` 本地赋值）并标注 `local-preview`。
- 这意味着“点击 → 控制 → 回写 → 3D 更新”是真实闭环，而不是前端自娱自乐。
- 实测证据：`POST /api/control {device:door,state:true}` 后，页面在 3 s 内门扇旋转 93.6°、门状态灯转绿，面板「门禁 已开启」；灯同理（`results/screenshots/3d_dooropen_light_1920x1080.png`）。

## 二、异常状态的提示现状（逐项核对）

任务书要求「明显提示，不能只靠颜色区分」。逐项判定：

| 异常 | 当前提示手段 | 是否“只靠颜色” | 判定 |
| --- | --- | --- | --- |
| 烟雾越界 | ① 顶部卡片「烟雾 xx%」变红 ② 3D 红色信标 `beacon`（位置 3.55, 2.86, -2.7）显隐 + 呼吸闪烁 ③ 3 层半透明烟雾云 | 否（有数值文字 + 显隐 + 动画），但**可视性差** | ⚠ 需加强（D-03） |
| 温度越界 | ① 卡片数值 + `warn` 色调 ② 空调模块变蓝/橙 ③ 环境指示牌变色 | **是（以颜色为主）** | ✗ 不达标 |
| 湿度越界 | ① 卡片数值 + `warn` 色调 ② 加湿模块自发光 | **是（以颜色为主）** | ✗ 不达标 |
| 光照过暗 | 卡片 `dim` 色调 + 光照计变橙 | **是** | ✗ 不达标 |
| 接口断连 | 右上角「模拟数据」文字 + 面板「门状态来源：本地演示」 | 是（仅文字替换，无警示样式） | ✗ 不达标（D-02） |
| 门禁拒绝/失败 | 页面「门禁 已关闭」+ `local-preview` 文案 | 部分 | 一般 |

**实测证据**：构造烟雾=180 的受控服务后截图（`results/screenshots/3d_alarm_1920x1080.png`），场景内红色信标被右侧墙体遮挡、烟雾云 opacity=0.16 几乎不可见，**画面上看不出“正在报警”**——说明现有异常提示不合格。

## 三、整改方案（第 8 周内完成，代码可直接落地）

### 3.1 统一“异常横幅”组件（覆盖烟雾/温湿度/断连）

```vue
<!-- 建议新增 src/components/StatusAlertBar.vue，挂在 Room3D 顶部 -->
<template>
  <div v-if="alerts.length" class="alert-bar" :class="`level-${top.level}`">
    <i class="fa-solid" :class="top.icon" />
    <span class="alert-text">{{ top.text }}</span>
    <span class="alert-time">{{ top.time }}</span>
  </div>
</template>
```

规则（后端字段优先，禁止前端另立阈值）：

| 条件 | 级别 | 文案 | 图标 |
| --- | --- | --- | --- |
| `smoke >= devices.alarm_threshold`（接口下发，缺省 100） | 危险 | 「检测到烟雾，已触发报警，请立即疏散」 | `fa-triangle-exclamation` |
| `temperature > temp_max + 1` 或 `< temp_min - 1` | 警告 | 「温度越界 27.3℃（设定 20-26℃）」 | `fa-temperature-high` |
| `humidity` 越界 | 警告 | 「湿度越界 xx%（设定 40-60%）」 | `fa-droplet` |
| 轮询连续失败 ≥ 2 次 | 危险 | 「接口断开，数据不可用（最后成功 hh:mm:ss）」 | `fa-plug-circle-xmark` |

规则要求：**文案必须带数值和设定区间**（文字提示，不依赖颜色）；危险级别同时做 3 件事——顶部横幅 + 场景内高亮（不遮挡）+ 面板数值闪烁边框。

### 3.2 3D 层强化（解决信标被墙体遮挡）

1. 报警信标改为**顶部悬浮环 + 垂直光柱**（`y=3.2` 起，半径 0.35），并对 `camera` 设置 `layers` 或 `depthTest: false` 保证不被墙遮挡；
2. 烟雾云 `opacity 0.16 → 0.45`、颜色 `0x9ca3af → 0xd1d5db`，并加 `emissive` 微弱自发光；
3. 报警时对全场景加淡红色 `fog`（`scene.fog.color`）与一次性镜头轻微震动，形成“非颜色通道”的感知（形状/运动/声音可选）。

### 3.3 阈值下发的接口改动（与第 8 周冻结接口同步）

`/api/current` 已返回 `temp_min/temp_max/humidity_min/humidity_max`，前端应改为：

```js
const hot = state.climate.temperature > Number(data.temp_max ?? 26);
const cold = state.climate.temperature < Number(data.temp_min ?? 20);
const wet = state.climate.humidity > Number(data.humidity_max ?? 60);
const dry = state.climate.humidity < Number(data.humidity_min ?? 40);
```

并在接口文档中新增 `alarm_threshold`（烟雾阈值），**一处配置、两端一致**（对应缺陷 D-04 / D-06）。

## 四、交互验收自检

| 判据 | 现场操作 | 通过标准 |
| --- | --- | --- |
| 有点击交互 | 鼠标点门扇 | 门开/关，且接口 `door_open` 同步变化 |
| 有旋转/缩放 | 拖拽、滚轮 | 视角变化平滑，无卡顿掉帧 |
| 有视角切换 | 点「全景/正前方/俯视」 | 相机跳转到预设，参数与文档一致 |
| 异常有明显提示 | 构造烟雾/温湿度越界/断连 | 出现文字横幅（非仅颜色），文案含数值与区间 |
| 提示不遮挡关键信息 | 观察场景 | 报警时不遮挡门/人员/表格区域 |
